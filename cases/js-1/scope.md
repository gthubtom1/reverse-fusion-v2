# scope.md — cases/js-1

**本案模式是 算法抽取（模式 3），验收词是「算法抽取：通过 / 部分通过 / 不通过」，不适用 L4/L5（不写「L4 通过」「新程序」）。**

- 目标类型：JS / 网页算法（自托管验证页）
- 目标：样本 `sig1`（简单）、`sig2`（中等），抽取其签名算法并在 Node 本地独立复现
- 样本来源：自己的测试页 `cases/js-1/target/`（v3 §6.3 允许自己的测试页），不在公网站点上做
- 要做：定位签名链路 → Node 重写算法 → 5 用例与浏览器原版基准对照（正常 2+ 边界 1+ 无效 1+ 比较器自检）
- 不做：不要求也不写 L4/L5；不重做整个页面 UI；不 eval/require 页面文件
- 验收：TC1/TC2 正常；TC3 边界（空串 / 长度 1）；TC4 无效（K 补位 / 大 nonce）；TC5 篡改常量后输出必须变 + 未见输入探针防背答案
