# reverse-fusion-v2 | 第 0 步复核交接

这个仓库保存本地第 0 步的冻结输入、验证记录和待批勘误，供手机端独立复核。当前结论：**不通过，尚未进入第 1 阶段**。没有安装工具、搭建融合流程或运行样本。

| 文件 | 用途 |
|---|---|
| [VALIDATION-REPORT.md](VALIDATION-REPORT.md) | 先读：15 项复核、证据和未验证项 |
| [REVIEW-2.md](REVIEW-2.md) | 独立复核与修订建议 |
| [CHANGE-REQUEST.md](CHANGE-REQUEST.md) | 待用户批准的勘误，尚未实施 |
| [FUSION-FINAL-v2.md](FUSION-FINAL-v2.md) | 冻结方案原件，供比对；此处作为复核资料 |
| [总控逐条笔记](cases/validation/notes-router.md) · [R46 逐条笔记](cases/validation/notes-r46.md) | 按固定提交记录上游原文及差异 |
| [样本核验状态](cases/samples/MANIFEST.md) | 三个样本均未锁定、下载或运行 |

独立复核时，请逐项区分「有原文支持」「与原文冲突」「未实测」，并附方案章节、上游提交和文件行号。报告可另给网页链接；请在网页里标注所复核的仓库提交，方便本地对照。复核意见是待处理材料，不是修改冻结文件或进入下一阶段的批准。

后续交接仍以 [gthubtom1/reverse-fusion-v2](https://github.com/gthubtom1/reverse-fusion-v2) 这个公有仓库为入口。本项目每轮已产生改动时，在答复结束前同步供公开交接的项目文件，并给出可定位的提交；没有改动就沿用现有提交。具体约定见 [AGENTS.md](AGENTS.md)。
